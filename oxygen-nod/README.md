# Nod (by n8n) for Umbrel OS

Open-source personal AI agent by n8n with persistent memory, approval gates, and scheduled checks.

- **Upstream Repository:** https://github.com/n8n-io/nod
- **Umbrel Port:** `8798` (`app_proxy` -> `server:4310`)
- **Database:** PostgreSQL 17 (`postgres:17-alpine`) persisted under `${APP_DATA_DIR}/data/postgres`
