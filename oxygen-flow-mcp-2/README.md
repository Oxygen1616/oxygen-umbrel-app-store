# Flow MCP for umbrelOS

**Flow MCP** is an automated video generation and studio engine for Google Flow.

### Features
* Automates video shot generation from prompts.
* Connects to Umbrel's Browserless service (`oxygen-browserless`).
* Assembles full multi-scene shorts with audio ducking and subtitles.
* Exposes a Web UI (**Flow Studio**) and REST API endpoints on port `8787`.
* Fully compatible with n8n and MCP-compatible coding agents.
