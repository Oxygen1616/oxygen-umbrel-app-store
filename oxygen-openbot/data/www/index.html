OpenBot

Local-first desktop workspace and self-hosted server for persistent AI teammates and multi-agent coordination.

Self-Hosted Server Active on Umbrel OS
Launch Web App (openbot.run) Download Desktop App Documentation

1 Pair Umbrel Server with Your Account

To make this Umbrel server available to your account, run this command in your Umbrel terminal or SSH session. It will send a quick verification code to your email:

docker exec -it oxygen-openbot_openbot_1 openbot login

Tip for server administrators: You can also link with an unattended claim URL using openbot login --claim.

2 Connect Mobile App (iOS / Android)

To pair your mobile device with this server, generate a Mobile Connect pairing code and QR code directly in the terminal:

docker exec -it oxygen-openbot_openbot_1 openbot mobile-connect

3 Check Server & Agent Status

Verify that your persistent agent runtime, local database, D-Bus session, and background workers are operating normally:

docker exec -it oxygen-openbot_openbot_1 openbot status

Key Capabilities

Local-First Sovereignty

Workspaces, chats, SQLite database, and cryptographic keyrings are persisted directly on your Umbrel storage volume.

Multi-Agent Swarms

Seamlessly coordinate Claude Code, Codex, Grok, OpenCode, Hermes Agent, and custom tools in unified channels.

MCP & ACP Native

Full support for Model Context Protocol servers and Agent Client Protocol execution with isolated containers.

P2P & WebRTC Remote

End-to-end encrypted direct peer-to-peer tunnels connect your desktop and mobile apps with zero data cloud leakage.
