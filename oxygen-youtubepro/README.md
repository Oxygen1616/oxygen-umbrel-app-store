# YouTube Pro for Umbrel OS

Research, understand, write, and package a YouTube video in one evidence-grounded, local-first workflow.

YouTube Pro combines public **YouTube Data API v3** records with **Google Gemini** analysis to turn search queries into decision-ready insights, validated ideas, production scripts, teleprompter sessions, and AI thumbnail generation.

---

## Features

- **Research Analytics**: Search topics, inspect publication velocity, compare momentum and patterns, and review data coverage.
- **Source Videos Grid**: Review all returned videos in the active snapshot with thumbnails, views, publication dates, and comment counts.
- **AI Insights**: Gemini generates audience questions, opportunity themes, and strategic moves directly from active evidence.
- **Grounded Ideas**: Turn insights into targeted video concepts with validated hooks and angles.
- **Script Teleprompter**: Write and edit scripts from selected ideas, regenerate sections with bounded context, and practice delivery with a customizable reading teleprompter.
- **Thumbnail Creator**: Generate 16:9 thumbnails from outcome promises and style references using Gemini imaging models.

---

## Configuration

1. Install **YouTube Pro** from the Oxygen Umbrel App Store.
2. Open YouTube Pro at `http://umbrel.local:8795` (or your Umbrel IP).
3. Go to **Settings** and enter your:
   - **YouTube Data API v3 Key** (Required for Research)
   - **Google Gemini API Key** (Required for Insights, Ideas, Scripts, and Thumbnails)
4. Select your preferred text and image models (e.g. `gemini-3.7-flash` and `gemini-3.1-flash-image`).
